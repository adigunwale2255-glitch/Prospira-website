# Prospira — Premium Digital Product Agency

A high-performance Next.js 15 digital product agency website built with TypeScript, Tailwind CSS, and Framer Motion.

## 🚀 Features

- **High-Impact Hero & 3D Showcase**: Interactive floating perspective showcase and animated bounce indicators.
- **Dynamic Stats & Animated Counters**: Scroll-triggered metric count-ups powered by Framer Motion.
- **Infinite Ecosystem Marquee**: Seamless partner/tech stack ticker.
- **Expertise & Services Grid**: 6 specialized service categories with glowing interactive hover states.
- **Interactive Project Cost Calculator** (`/services`): Real-time scope selection (Web, Mobile, SaaS, UI/UX) with feature add-on toggles and dynamic total calculation.
- **Filterable Case Studies** (`/portfolio`): Masonry grid with category filtering (All, Web, Game Dev, SaaS, Systems) and animated hover overlays.
- **The Prospira Way** (`/process`): 5-step alternating timeline with central step badges.
- **Manifesto & Principles** (`/about`): System evolution philosophy and the 4 "Built to Last" tenets.
- **Contact & AI Project Advisor** (`/contact`): Inquiry form and an interactive AI Advisor generating custom tech stacks and 4-phase roadmaps.
- **Magnetic Custom Cursor**: Spring-physics magnetic cursor with interactive target scaling.
- **Live Scroll Reading Progress**: Top/right reading progress indicator.

## 🛠️ Tech Stack

- **Framework**: Next.js 15 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Motion & Animations**: Framer Motion
- **Icons**: Lucide React
- **Typography**: Space Grotesk & Inter

## 💻 Local Development

```bash
# Install dependencies
npm install

# Start Next.js development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the application.

Or run the lightweight standalone server:

```bash
node server.js
```
